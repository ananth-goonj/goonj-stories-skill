# Pitfalls found in earlier reviews

Read this before a large run. Each item came from a real run.

- **Hidden text.** If the file reader misses headers, footers or text boxes, every "not stated" about codes, writers and places is wrong. The scan lists what it read; check the footer lines show up in a story text before you trust the batch.
- **Legacy Hindi fonts.** Some Word files use an old font that turns Hindi into garbled Latin letters. The scan warns about these. Do not review them: ask for a Unicode copy.
- **Old `.doc` files and PDFs.** They are not read. Open the file and save it as `.docx`.
- **Reused text.** Two stories can carry the same testimony under different names. The scan marks reused-text families; they count once where it matters, and the testimony flag stays on both.
- **Template and writer effects.** In every batch so far, writer, format and place were tangled together. A difference between groups of stories is often a difference between formats. Findings name templates, never people.
- **Translation.** In a translated batch every quote is the translator's rendering, a word may be a translation slip, and words such as "collective" may exist only in English. Counts of words say how the English reads.
- **Denominators.** "3 of 8" and "3 of 100" are different findings. A field that most stories lack makes every share from it small and shaky.
- **Stock phrases.** "Everyone decided together" is a writing formula, not a described process. It is `asserted`, and a Key Question answered only by it is `partial`.
- **Dates.** A range is not a count of days. A date with no year is inferred only from another date in the same story. A story filed months after the work looks late only if you compare the right dates.
- **Women-only counts.** A count of women who worked is a minimum. It is never a total and never a share.
- **Meeting numbers.** People at a meeting are not people who did the work.
- **Names and sensitive details.** A named person with a health, injury, bereavement or menstrual detail is never shown beside that detail. The gate refuses a record whose text has such words but no flag; the report and the workbook mask the names the records list.
- **Absence.** A gap in a story is a gap in the write-up, not in the village.
- **Big batches.** Cost grows with the number of stories. Try a pilot of three stories first, check that two readers agree on the Key Question statuses (about 80 percent or more), then run the rest.
- **Agents that cannot run side by side.** If the session cannot start several agents, a Quick check still works story by story; a Full review is slow.
- **Windows.** The scripts read and write UTF-8 themselves. If a Hindi quote looks wrong in a terminal, the files are still right: open the report or the workbook.
- **Changing a question's wording** after stories were read changes what the answers mean. Ask for a targeted re-read of that question; the batch file records the question-set version.
